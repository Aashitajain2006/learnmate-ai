# LearnMate AI — IBM SkillsBuild Project Submission Pack

## Files
- `index.html` — interactive browser prototype (rule-based demo; no backend).
- `Concept_Note_LearnMate_AI.pdf` — concept note.
- `Lean_Canvas_LearnMate_AI.pdf` — lean canvas.
- `Final_Deliverable_LearnMate_AI.pptx` — final presentation.
- `Project_Screenshots.pdf` and `screenshots/*.png` — UI mockup screenshots.

## Before submitting
1. Replace `[Your Full Name]` and `[Your College Name]` in the concept note/PPT with your actual details.
2. Open `index.html` in Chrome and click **Create my learning plan**. Capture real screenshots of the working demo if your mentor expects actual application screenshots; the included images are labeled mockups.
3. The Google Form asks for a project URL. A local HTML file is not a public URL. To create a URL, upload `index.html` to a GitHub repository and enable GitHub Pages, or deploy the folder to Netlify. Then paste the resulting public URL into “Insert final Project Link for Review”. Do not paste a made-up link.
4. Upload the concept note PDF, PPTX, and screenshot PDF/images in their respective fields. The form says it accepts one file per upload field; if needed, combine screenshots into the included PDF.
5. This is a prototype concept, not a production AI system. Be honest about that if asked.

## Quick GitHub Pages route
- Sign in to GitHub and create a public repository, e.g. `learnmate-ai`.
- Upload `index.html` to the repository root.
- Open **Settings → Pages**, choose deployment from the `main` branch and `/ (root)`, then save.
- Wait for GitHub to show the published site URL and test it in an incognito window.
